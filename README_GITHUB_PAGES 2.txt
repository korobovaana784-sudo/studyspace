STUDYSPACE — ПАКЕТ ДЛЯ ПУБЛИКАЦИИ

Внутри находятся файлы статического сайта и PWA. Платить за App Store или Google Play не нужно.

ПУБЛИКАЦИЯ ЧЕРЕЗ GITHUB PAGES (С IPHONE)
1. Откройте https://github.com/ в Safari и войдите или создайте аккаунт.
2. Нажмите + → New repository.
3. Название: studyspace. Выберите Public. Нажмите Create repository.
4. В репозитории выберите Add file → Upload files.
5. Загрузите ЧЕТЫРЕ файла из этого архива: index.html, manifest.webmanifest, sw.js, icon.svg. Важно: загрузить сами файлы в корень репозитория, не архив ZIP и не папку.
6. Нажмите Commit changes.
7. Откройте Settings → Pages.
8. В разделе Build and deployment выберите Deploy from a branch.
9. Branch: main; folder: /(root). Нажмите Save.
10. Подождите несколько минут. Ссылка будет вида https://ВАШ-ЛОГИН.github.io/studyspace/.

УСТАНОВКА НА IPHONE
Откройте полученную ссылку в Safari → Поделиться → На экран Домой → Добавить.

УСТАНОВКА НА ANDROID
Откройте ссылку в Chrome → меню ⋮ → Установить приложение / Добавить на главный экран.

ВАЖНО
- Не публикуйте пароли, ключи API или личные данные в репозитории.
- Этот пакет — первая версия интерфейса. ИИ, облачная синхронизация и полные базы учебников/ГДЗ пока не подключены.
- Данные прототипа хранятся в браузере конкретного устройства.
- GitHub Pages подходит для статического сайта. Для серверной части и безопасного ИИ позже понадобится отдельный сервер.
- Бесплатные тарифы и условия платформ могут меняться.
